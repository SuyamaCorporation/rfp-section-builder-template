# RFP Request for Proposal Section Template Builder

A structured document builder for creating professional Request for Proposal documents with a live preview, clipboard copy, and text file download.

## Features
- Fill in project metadata: Project Name, Organization, Issue Date, Due Date, Contact Name and Email
- Seven editable sections: Project Overview, Scope of Work, Deliverables, Timeline, Evaluation Criteria, Budget Range, Submission Instructions
- Tabbed interface switching between Edit and Preview modes
- Preview renders formatted HTML output; Copy button exports as plain text; Download saves as a .txt file
- localStorage autosaves all content as you type — no data lost on refresh
- XSS-safe rendering for all user input

## Usage
Fill in the form fields and section text areas, then click Preview or the Preview tab to see your formatted RFP. Use Copy Text to put it on the clipboard, or Download .txt to save it locally.
